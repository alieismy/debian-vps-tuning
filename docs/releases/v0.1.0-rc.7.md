# v0.1.0-rc.7

这是 `debian-vps-tuning` 首发候选版本的第七轮整改，修复 rc.6 在真实 Debian 12 VPS 上暴露的两个只读验证缺陷。

## 目标机结论

rc.6 已成功隔离 rc.2 遗留的空状态，1000 Mbps `preflight` 通过。`apply` 写入预期配置后，内核返回：

```text
4096       131072  33554432
4096        65536   33554432
```

配置文件中的期望值使用单空格。两组字段数值完全一致，但 rc.6 逐字符比较，导致 `verify` 误报并触发自动回滚。日志最终报告“回滚完成，管理状态已清理”，所以该目标机没有遗留 rc.6 管理状态。

同一轮日志中的 `NOFILE soft=524287 524288 hard=` 也属于显示解析错误。脚本全局 `IFS` 不包含空格，而旧解析器用空格分隔 soft/hard，两个值因此进入同一变量。目标进程的实际 soft/hard limit 没有被脚本修改。

## 修复

- sysctl 校验将首尾空白以及连续空格/制表符归一为单空格，再严格比较字段值；
- 回滚完成判断对原始 sysctl 使用相同规则；
- NOFILE 解析器用制表符明确分隔 soft/hard，并在读取点显式设置 `IFS`；
- 为两种缺陷增加独立回归测试；
- README 的目标 VPS 命令全部按 root shell 编写。

## 发布边界

rc.7 后续已在 Debian 12 1C2G、200 Mbps 目标机完成 `preflight`、`apply`、立即/重启后 `verify`、重复 `apply`、严格 3X-UI/Xray 验证、`rollback`、回滚后重启、重新 apply 和最终重启后严格验证。实际恢复结果正确，但恢复命令后缺少删除状态前的 qdisc 后置语义比较；该缺口在 rc.8 修复。rc.7 保持预发布历史记录，不作为正式稳定版。
