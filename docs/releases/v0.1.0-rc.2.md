# v0.1.0-rc.2

这是 `debian-vps-tuning` 首发候选版本的第二轮整改，修复静态评审发现的 qdisc 回滚、未安装验证提示和 swap 文件系统预检问题。

## 修复内容

- 根 qdisc 已是 `fq` 时，应用和回滚均不再执行无意义的 `tc qdisc replace ... root fq`；
- `mq` 下已经是 `fq` 的叶子保持不变，只把支持恢复的 `fq_codel` 叶子切换为 fq；
- `verify` 在不存在项目状态时返回明确提示和退出码 5；
- 自动 swap 文件允许 `ext2`、`ext3`、`ext4` 和 XFS；
- Btrfs、ZFS、overlay、NFS、FUSE 及未知文件系统跳过自动创建 swap，但继续应用其他网络配置；
- 静态测试增加上述行为的不变式检查；
- 验证文档补齐 T1–T6 目标机、M0–M11 生命周期和 Q1–Q5 qdisc 回归矩阵。

## 发布状态

这是预发布版本。生成一致性、语法、ShellCheck、编码、结构和校验和检查通过后仍需在 Debian 12/13 目标 VPS 上完成 apply、重启、重复执行、回滚和业务连接验证。
