# v0.1.0-rc.17 发布说明草案

状态：未发布实现候选

## 变更摘要

rc.17 修复 HTB 研究证据链，不改变默认调优参数。benchmark 现在识别
`parent MAJOR:MINOR` 形式的 FQ 叶 qdisc；phase summary 升级为 schema 3，分别保存
root/leaf totals 和本地 drop/requeue 健康状态。候选速率 analyzer 要求完整的
HTB→FQ 拓扑证据，旧 schema、缺字段或任一 root/leaf drop/requeue 都会形成
`REVIEW_BLOCKED`，shortlist 为空。HTB root `overlimits > 0` 仍只表示整形器实际工作。

脱敏 `socket-metrics.txt` 新增 `pacing_rate`、`delivery_rate`、`minrtt`、
`dsack_dups`、`rcv_ooopack`、`snd_wnd` 和 `rcv_wnd`，用于后续区分 pacing、
delivery、乱序和窗口限制。输出仍不包含 socket header、endpoint、端口、PID、进程名或 inode。

## 保持不变的边界

- 17 项受管 sysctl、资源感知 BDP 缓冲、默认 `BBR + fq` 和 managed-state schema 4 不变；
- HTB 仍为非持久、显式授权、受预算约束的上传研究入口；
- 本版不修改 HTB rate、burst/cburst、quantum 或 FQ 参数；
- 本版不启用持久 HTB，不连接真实 VPS，也不产生公网测试流量；
- 本地 fixture 不能证明服务商 policer、目标 VPS 重传根因或真实业务改善。
