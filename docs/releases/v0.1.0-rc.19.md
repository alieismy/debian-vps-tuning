# v0.1.0-rc.19

状态：Pre-release；基于已发布且保持不可变的 rc.18。此版本不代表稳定版或目标 VPS 的生产验收。

本版吸收 receiver 背离复核、swap 管道修复和锁冲突诊断，并交付实测校准第一阶段。详细行为与证据契约见 [实测校准说明](../measured-calibration.md)。新增离线 Python 工具从源码仓库使用，不进入当前 Shell 安装资产，也不增加 VPS 运行依赖。

默认 BBR + fq、17 项 sysctl、BDP 资源档位、managed-state schema 4、benchmark schema 3、流量预算和非持久 HTB 边界保持不变。迁移器支持 rc.1–rc.18 来源进入 rc.19，仍要求 checkpoint、恢复和两次重启门禁；旧 ledger 不被静默升级，当前版本不兼容的 ledger 必须按既有生命周期处理。

## 验证边界

本地适用门禁与当前执行结果记录在 [项目备忘](../project-memo.md)。包含校准器 0.1.1 和 rc.17 兼容增量的 PR #19 已合并；其 [最终提交 Linux CI](https://github.com/alieismy/debian-vps-tuning/actions/runs/36319780316) 和 [合并后 master CI](https://github.com/alieismy/debian-vps-tuning/actions/runs/36319866982) 均通过，包括 33 项 Python 测试、真实 flock 竞争、静态/HTB 套件、root installer、rc.17/rc.18 来源迁移 fixture 和 ShellCheck 0.11.0。2026-09-27 一份 rc.17/iperf3 3.18 的真实完整上传 probe 已通过本地离线格式核验，代表性出向路径的结论为 `KEEP_CURRENT_CEILING`；其他版本/方向、目标 VPS 生命周期、真实代理业务和收益均不能由这一例代替。
