# v0.1.0-rc.3

这是 `debian-vps-tuning` 首发候选版本的第三轮整改，修复 Debian 12 1C1G、1000 Mbps 目标 VPS 在 `apply` 状态初始化阶段暴露的 jq 编译错误。

## 修复内容

- 将状态 JSON jq 变量从保留字 `label` 改为 `profile_label`；
- 原子 JSON 写入失败时删除不完整临时文件；
- 状态尚未提交时失败，只清理本次进程创建的状态目录和 qdisc 快照，并明确报告尚未写入系统配置；
- 静态测试从四份生成脚本提取状态 JSON jq 过滤器，使用实际 jq 编译并验证关键字段。

## 目标机证据

已确认 Debian 12、1C1G、1000 Mbps 目标 VPS 的 `preflight` 通过：根 qdisc 为 `fq_codel`，系统已有 `/dev/dm-0` swap，脚本选择 32 MiB socket 上限。rc.2 的 `apply` 在写入任何系统配置前因 jq 保留字失败；修复后的 `apply`、重启验证、重复应用和回滚仍待执行。

## 发布状态

这是预发布版本。不得把 rc.2 的失败运行计为 apply 通过，也不得在缺少 rc.3 目标 VPS 运行证据时发布稳定 `v0.1.0`。
