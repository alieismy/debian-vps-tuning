# v0.1.0-rc.4

这是 `debian-vps-tuning` 首发候选版本的第四轮整改，处理 Debian 12 1C1G、1000 Mbps 目标 VPS 在 rc.3 中暴露的残留状态、参数冲突信息不足和无诊断回滚失败。

## 修复内容

- 引入 `APPLYING` 事务阶段，并保证在首个系统写入前提交；
- 对 `PREPARED`、`ROLLBACK_PENDING` 和 `DEGRADED` 状态执行严格的“已经恢复”检查：项目文件不存在、swap 未由脚本创建、qdisc 与原始快照语义一致、原始 sysctl 已恢复时，安全清理事务状态；
- qdisc 快照比较忽略运行时 `refcnt` 和 JSON 字段顺序，但不会忽略 kind、handle、parent、root 或 options 差异；
- 回滚按步骤输出失败原因，不再只报告“回滚不完整”；
- 参数冲突同时显示保存的 port/RTT/buffer 和当前计算值。

## 目标机证据

已确认 rc.3 jq 状态构造器问题修复生效。目标机当前存在有效但参数不匹配的事务状态，手动 rollback 进入不完整状态；rc.3 没有打印保存参数和具体失败步骤，因此不能仅凭现有日志确认最初状态的来源。rc.4 用语义状态检查恢复该场景，并在无法恢复时输出具体失败步骤。

## 发布状态

这是预发布版本。rc.4 必须先在该目标 VPS 完成 rollback/status、1000 Mbps apply、verify、重启 verify 和重复 apply，才能把相应矩阵项标记为通过。
