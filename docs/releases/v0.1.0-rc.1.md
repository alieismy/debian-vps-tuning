# v0.1.0-rc.1

这是 `debian-vps-tuning` 的首个预发布版本，面向 Debian 12/13、1 vCPU、1/2 GiB RAM、100–1000 Mbps 端口的小型代理 VPS，默认按 200 Mbps 调优。

主要验收场景是原生 systemd 部署的 3X-UI v3.4.2、Xray-core v26.6.27、VLESS + REALITY + TCP。四份脚本也可用于 S-UI、sing-box 或独立 Xray 主机，但不会读取、修改或重启代理服务。

## 本版本包含

- Debian 12/13、1C1G/1C2G 四份独立脚本；
- BBR + fq 能力预检及可恢复的 qdisc 处理；
- 按端口速率和目标 RTT 分档的 TCP 缓冲；
- 固定路径、受限容量且带所有权验证的应急 swap；
- journald 空间限制；
- `preflight`、`apply`、`verify`、`status` 和 `rollback`；
- root-only JSON 状态、管理文件 SHA-256 和事务失败回滚；
- 3X-UI/Xray systemd 服务与进程 `NOFILE` 的只读核验；
- 中文 README、设计边界、目标 VPS 验收步骤和 GitHub Actions 静态检查。

## 发布状态

这是 release candidate，不是目标 VPS 运行验收完成后的正式稳定版。本地已完成生成一致性、`bash -n`、ShellCheck 0.11.0、编码、禁用 sysctl 键和结构检查；BBR、fq、重启持久性、回滚、UFW、3X-UI 与真实客户端连通性仍应按 `docs/validation.md` 在目标 VPS 上验证。

## 下载后校验

同时下载所需脚本与 `SHA256SUMS`，在同一目录执行：

```bash
sha256sum -c SHA256SUMS
```

只需要运行与 Debian 主版本和内存档位匹配的脚本。不要直接使用 `curl | bash`。
