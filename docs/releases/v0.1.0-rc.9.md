# v0.1.0-rc.9（发布草案）

这是 `debian-vps-tuning` 首发候选版本的第九轮变更，新增安全总控入口、512 MiB profile、按资源约束的缓冲/journald、3X-UI NOFILE 预置、常规 `pfifo_fast` 回滚和只读诊断，并把现有 2G 档位扩展为支持 1–2 vCPU。状态 schema 保持为 3。

## 新增总控入口

- 新增 `debian-vps-tuning.sh`；
- 自动识别 Debian 12/13、amd64 和 1C512MB、1C1GB、1C2GB、2C2GB 四个资源档；
- 2G 档保留 `1c2g` 文件名和 profile ID，1C2GB/2C2GB 共用实现以兼容已有状态；
- 带宽默认 200 Mbps，允许 100–1000 Mbps；
- 默认安全引导先执行 preflight，只有再次明确确认才 apply；
- 支持 `preflight`、`apply`、`verify`、`status`、只读 `diagnose`、`rollback` 和高级 `recover`；
- 512M/1G/2G socket 上限分别为 16/32/64 MiB；预置 `x-ui.service` 的 `LimitNOFILE=65536`；
- 支持常规默认根 `pfifo_fast` 的快照、切换、恢复和后置语义验证；
- 本地和远程 profile 均在调用前核对唯一 SHA-256 清单条目；
- 远程模式固定到 `v0.1.0-rc.9`，只允许 HTTPS，不回退可变分支、latest 或第三方源；
- 保留底层 profile 的原始输出和退出码。

## 发布边界

rc.9 是预发行版。固定 Release assets 的真实下载只有发布后才能验证；交互确认、总控入口、512 MiB、2C2G、Debian 13、常规 `pfifo_fast` 和 1/3/5/10 并发业务矩阵仍需目标机证据。rc.8 的运行证据不能替代 rc.9 总控入口和 profile 版本的实机复测，因此不得标记为正式 `v0.1.0`。
