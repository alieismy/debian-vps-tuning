## R1 — Major：下载 Release 资产后缺少还原目录结构的步骤

- **位置：** [操作指南](usage.md) 341–350、405–408 行；由中文 README 151、175 行和英文 README 151、177 行进入。
- **评审轴：** 证据准确性、操作完整性。
- **问题：** 文档要求“从 GitHub Release 下载完整资产”后执行 `sha256sum -c SHA256SUMS`，并提供 `bash install.sh --source-dir "$PWD" --no-launch`。但没有说明 Release 文件名与本地 bundle 目录结构不同。
- **依据：** [SHA256SUMS](../SHA256SUMS) 的五项实验资产位于 `experiments/htb-aggregate/`；[安装器](../install.sh) 127–138 行在联网下载时以 `basename` 获取资产并主动创建逻辑目录，离线 `--source-dir` 则要求文件已处于清单指定的相对路径。
- **复现：** 使用全部已校验的本地资产模拟平铺下载目录，执行文档中的 `sha256sum -c SHA256SUMS`，返回 1，五项实验文件报不存在。使用相同字节的文件恢复清单目录结构后，同一命令返回 0，24 项全部通过。没有执行安装器或系统写入。
- **影响与分级：** 按该分支准备离线包会在校验或安装前失败；用户已经下载完整资产仍无法继续。属于实际操作路径缺口，定为 Major。它不会导致执行错误资产，现有校验会拒绝，故不定为 Critical。
- **整改：** 区分“平铺的 Release 下载文件”和“按清单目录组织的 bundle”，补充五项实验文件的目录还原步骤，随后执行完整摘要检查和离线安装。保留 manifest 的可信固定摘要要求。不能要求用户改清单或跳过缺失文件。
- **复审条件：** 从模拟平铺目录按修订步骤构建 bundle；确认 24 项清单摘要通过，安装器预期的所有逻辑路径存在。实际 Linux root 安装应另标其运行证据，不能用本次本地布局复现替代。
- **来源与分配：** 重构前中文 README 492–505 行已有该缺口，本次搬迁继续保留；负责人/完成日期未分配。
