# 自动测量：单机低流量功能验收记录

日期：2026-09-28（Asia/Singapore）。性质：经用户授权执行的运行证据记录；本次有限范围验收通过，不构成发布、持久配置、性能收益或所有平台的验收。

## 对象与范围

- 源码固定于 `d650709db9f385938c8ec03f903ab4f977ff718c`，版本为 `0.2.0-rc.1`。部署使用独立私有目录中的完整 21 文件 bundle，逐项校验 20 个安装资产摘要；没有运行安装器、apply、迁移或切换已有 `dvt` 入口。
- 目标为一台 Debian 13 / x86_64 / 1 vCPU / 2021216 KiB 内存主机，内核 `6.12.107+deb13-amd64`、Python 3.13.5、iperf3 3.18；原有 managed-state schema 4，rc.16，`VERIFIED`。主机地址、登录密钥与原始网络标识不进入公开记录。
- 自动选择公共 IPv4 端点，最多 2 次尝试；目标速率为 1、2 Mbps，每档 3 次 × 5 秒，首尾 1 Mbps 控制；流量调度期限 150 秒。完整测量及中断用例共用同一 64 MiB payload 账本，不重置、不扩额。
- 验收覆盖自动选点、真实采集、报告完整性、失败保守结算、SIGINT/SIGTERM 清理与配置前后观察。中断用例最终使用只监听 loopback 的临时自有服务，公共端点与本地中断证据分开解释。

## 预算与失败处置

完整公网测量连同成功预检按 sender bytes 结算 **8519680 bytes（8.125 MiB）**。最终账本包含 10 笔 `COMMITTED`、3 笔 `FAILED_CONSERVATIVE`，累计记账 **22165408 bytes（约 21.139 MiB）**，总额度 67108864 bytes，未结算预留为 0。三笔保守扣账分别对应公共节点 busy、SIGINT 和 SIGTERM；最终记账值不是实际公网流量，也不包含协议、重传及服务商计费开销。

第一次启动在资产权限检查处退出 2：Git 导出包在 root 解包时保留了 group-write 位。该次尚未创建账本或发出流量。只修正独立 bundle 的目录/文件权限后，保持源码摘要不变再运行；原始失败记录已保留。没有放宽测量工具的 root 所有权与不可 group/world 写入检查。

公共节点 busy 后，没有换账本或不断重试同一服务；信号用例改为同一目标主机上的 `127.0.0.1` 临时服务，运行生产测量调度器与 runtime，结束后只关闭本次创建的服务。采集与清理代码没有因本轮测试而修改。
